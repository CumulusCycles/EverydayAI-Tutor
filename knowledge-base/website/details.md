# EverydayAI Tutor — Site and Channel Details

## Who Created This Site?

EverydayAI Tutor was created by **Rob Frenette**. Rob is the founder, host, human developer, and the person behind all content decisions for the EverydayAI Tutor channel and website.

The site itself — the code, infrastructure, and deployment pipeline — was built entirely using **Claude Code**, Anthropic's agentic AI coding tool. Rob directed the build in plain language, Claude Code wrote every line of code and opened pull requests, and the site was deployed automatically to AWS on each merge. In this sense, both Rob Frenette (as the human creator and director) and Claude Code (as the AI that built it) are creators of this site.

When someone asks "who made this site?", "who created aieverydaytutor.com?", "who is behind EverydayAI Tutor?", or "who built this website?" — the answer is **Rob Frenette**, with the site built using Claude Code.

## About Claude Code

Claude Code is an agentic AI coding tool made by Anthropic. It reads an entire codebase, understands context, writes code, runs tests, and opens pull requests — all from plain-language descriptions. EverydayAI Tutor is a real-world example of a production site built entirely with Claude Code, with no human writing code directly.

Claude Code is **not** the host or human creator of EverydayAI Tutor. It is the AI tool that Rob used to build the site.

## How Was This Site Built?

- **Frontend:** React + Vite + TypeScript, deployed as a static site on AWS S3 + CloudFront
- **AI tool used to build it:** Claude Code (Anthropic)
- **Infrastructure:** AWS (Route 53, CloudFront, S3, API Gateway, Lambda, Bedrock)
- **Chatbot:** Powered by Amazon Bedrock Knowledge Base with S3 Vectors — RAG pattern
- **CI/CD:** GitHub Actions with OIDC authentication — no long-lived credentials
- **Human creator and director:** Rob Frenette
- **Full prompt log:** Available in the GitHub repository at https://github.com/CumulusCycles/EverydayAI-Tutor
