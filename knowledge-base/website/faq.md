What is EverydayAI Tutor?

EverydayAI Tutor is a YouTube channel and companion website for everyday people who want to learn how to understand and use artificial intelligence. It takes viewers step by step from understanding what AI is all the way to using it confidently in daily life and work — no technical background required.

Who is this channel for?

The channel is for complete beginners with no technical background, people who feel left behind by the pace of the AI revolution, curious adults who want practical skills rather than theory, professionals who want AI to improve their productivity, and anyone who has tried ChatGPT once but doesn't know where to go next.

Do I need a technical background?

No. EverydayAI Tutor is designed from the ground up for people without a technical background. Every concept is explained in plain English, no jargon is assumed, and the learning path starts from absolute zero.

Who created this site and channel?

EverydayAI Tutor was created by Rob Frenette. Rob is a full-stack developer, cloud engineer, and educator who is also an AWS Community Builder in AI Engineering. He built this channel because most AI educational content assumes a technical audience — EverydayAI Tutor is for everyone else. His LinkedIn profile is at https://www.linkedin.com/in/robertmfrenette.

How was this site built?

The site was built entirely using Claude Code, Anthropic's agentic AI coding tool. No human developer wrote code directly. Rob described what he wanted in plain language, Claude Code wrote the code and opened pull requests, and the site was deployed automatically to AWS on each merge. The full prompt log is in the GitHub repository. More details are on the Built with AI page at aieverydaytutor.com/built-with.

What is Claude Code?

Claude Code is an agentic AI coding tool made by Anthropic. Unlike a code autocomplete tool, Claude Code reads your entire codebase, understands the context, writes code, runs tests, and opens pull requests — all from a plain-language description of what you want to build. It is AI that acts, not just suggests. More information is at https://claude.ai/code.
